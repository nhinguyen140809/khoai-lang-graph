# ESLint config of the frontend

`eslint.config.js` only joins the blocks of `configs/`, in a fixed order. A later block replaces the
whole option list of a rule such as `no-restricted-imports` or `no-restricted-syntax` for the files
it matches, so each block repeats the lists it keeps, and the order of the joins is part of the rules.

```
lint/
├── configs/   one file for each concern; each exports a list of blocks
├── lib/       the data and the helpers that the blocks read: <topic>/<subject>.constants.js|utils.js
├── plugin/    the local rules (prefix local/)
└── tsconfig.json   type check of this folder (allowJs, checkJs)
```

## Where a change goes

| I want to                                                    | Edit                                                                                                                                                                                                                                           | Then                                                                                                                                                                                                                                                          |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ban a code pattern (a syntax shape, a call, a JSX attribute) | add a group to `lib/syntax/syntax-groups.constants.js`                                                                                                                                                                                         | name it in `everyFile` of `configs/syntax.js` when every file follows it; otherwise in the blocks that do. The blocks that do not spread `everyFile` (tests, endpoint tests, `ui/`, `chart.tsx`, `typed-route`) list their groups by hand, so decide for each |
| Ban an import for every file                                 | add a pattern to `lib/imports/public-api-patterns.constants.js` (slice index) or `lib/imports/folder-index-patterns.constants.js` (folder index)                                                                                               | `sharedCodePatterns` in `shared-patterns.constants.js` repeats the folder-index ones; add it there too. `configs/__tests__/guards.test.js` checks that a pattern every file follows survives the later blocks                                                 |
| Ban an import for one place                                  | `lib/imports/*-patterns.constants.js` for the data, the `configs/imports-*.js` file of that place for the block (`imports-shared`: `src/shared`; `imports-mocks`: `src/mocks`; `imports-slices`: slices of modules; `imports-e2e`: Playwright) | the block lists every pattern it keeps, with `restrictImports({ paths, patterns })`                                                                                                                                                                           |
| Ban an import of a library outside its wrapper               | `lib/imports/wrapped-libraries.constants.js`                                                                                                                                                                                                   | nothing else; every block already spreads it                                                                                                                                                                                                                  |
| Let a module import another module                           | `lib/modules/module-imports.constants.js`                                                                                                                                                                                                      | `assertModuleTable` rejects a cycle and a module without a list                                                                                                                                                                                               |
| Add a kind of file (`<subject>.<kind>.ts`)                   | `lib/file-names/file-kinds.constants.js`: `fileKinds` for the places that hold it, `kindFolders` if a slice gets a folder for it                                                                                                               | `src/mocks` kinds also go in `mockTiers` of `configs/imports-mocks.js`; add the kind to CONTRIBUTING                                                                                                                                                          |
| Add a place with its own kinds                               | a row in `kindPlaces` of `file-kinds.constants.js`                                                                                                                                                                                             |                                                                                                                                                                                                                                                               |
| Add a banned or retired name                                 | `lib/names/vague-names.constants.js` or `lib/names/retired-words.constants.js`                                                                                                                                                                 |                                                                                                                                                                                                                                                               |
| Add a naming rule that needs types, or a new check           | a file in `plugin/`, registered in `plugin/index.js`, switched on in `configs/names.js` (`configs/imports-slices.js` for `slice-boundary`)                                                                                                     | a test in `plugin/__tests__/` with `createRuleTester` or `createTypedRuleTester`                                                                                                                                                                              |
| Relax a rule for a folder                                    | a block at the end of the config of that concern, never earlier than the block it relaxes                                                                                                                                                      | check with `ESLint.calculateConfigForFile` for a file of the folder                                                                                                                                                                                           |

## Checks

- `pnpm vitest run --project lint` runs the tests of this folder.
- `npx tsc -p lint/tsconfig.json --incremental false` type checks it.
- After a change that moves rules between blocks, compare `calculateConfigForFile` of every file
  before and after; the rules of a file must differ only where the change means them to.
